--- 5.3  The crash hook (needed for demo 2)
A worker cannot be killed "after the write and before the commit" by hand: the window is a few milliseconds. consumer.py now has
demo_crash_if_armed(): if the file /tmp/p06-crash-before-commit exists inside the worker container, the worker deletes the file (so it
fires once) and calls os._exit(137) right after the handler finished and before consumer.commit(). Without the file it does nothing.
A unit test proves: not armed -> nothing; armed -> killed after the write, offset not committed; after the "restart" the same message
is read again, answered "duplicate", and then committed (test_the_demo_hook_kills_the_worker_after_the_write_and_before_the_commit_only_when_armed).

(3) kind load docker-image failed ("ctr: content digest sha256:fa5f5a34... not found", after 1 min 29 s, nothing loaded). Docker Desktop's image
